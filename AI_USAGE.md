# Generative AI usage

Generative AI assisted with architecture and implementation planning for NeuroAnnotate and,
where used, with drafting code and documentation. AI-generated suggestions are treated as
untrusted contributions rather than authoritative output.

Maintainers review and test accepted changes, verify them against the repository's research-only
scope and data contracts, and retain responsibility for the resulting software and
documentation. Generative AI is not part of the application's inference workflow, and v1 does
not send uploaded NIfTI data to a generative-AI service.
